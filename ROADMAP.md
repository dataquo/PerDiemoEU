# PerDiemo — Public Product Roadmap

Welcome to the public roadmap for **[PerDiemo](https://www.perdiemo.eu)**. Here you can track active features, planned capabilities, and upcoming statutory enhancements.

Have a feature request or need support for a specific accounting standard?  
👉 **[Open a Feature Request](https://github.com/dataquo/PerDiemoEU/issues/new)**

---

## 🟢 Released & In Production (v1.0.x)
- [x] **Full Statutory Compliance Engine**: Czech Labour Code §§ 163, 170, and 183.
- [x] **ČNB Daily Exchange Rate Synchronization**: Automated daily fixing pipeline for decisive exchange rates.
- [x] **Multi-Country European Route Resolution**: Automated border crossing calculation with OSRM and geocoding.
- [x] **Dual-Language Interface**: Complete Czech (`cs`) and English (`en`) localized UI and documentation.
- [x] **Audit-Ready Exports**: Read-only PDF, CSV, JSON, and XML accounting export formats.
- [x] **AI Travel OCR**: Extraction of flight/train tickets, boarding passes, and accommodation invoices.

---
